How to analyse a plate

  1. Load data. Upload the export straight from the instrument (no reformatting needed): QuantStudio Melt Curve Raw data (.xlsx or .csv), or any table with a Temperature column and one column per well (e.g. Bio-Rad CFX Melt Curve RFU). If the file holds several assays, choose one under Data → Target. Optionally upload sample names (download the template first). All settings are in the menus along the top.
  2. Check the melt regions. Pick Raw above the plot. The blue band (pre-melt) and red band (post-melt) should sit on flat stretches just before and just after the melt. MeltScope suggests them automatically; drag the sliders under Melt regions to adjust.
  3. Look at the Normalised and Difference plots. Curves that group together have the same melting behaviour. The difference plot subtracts a reference (your control wells if you marked any, otherwise the largest group) so that small shape differences are easy to see.
  4. Check the calls on the plate map. Each well gets a variant and a confidence. If you know how many genotypes to expect, set Number of variants instead of Auto. Give the variants names (e.g. WT, Het, Hom) once you know which is which, for example from control wells.
  5. Mark control wells (optional), like Task/Control in Thermo's HRM software: select the wells, type a name below the plate map (e.g. Ch WT) and click Mark control. Repeat with another name for a second control (e.g. MV WT). Controls get a white triangle, each group holding controls is named after them (the other groups are Variant 1, 2…), and the Difference plot can use any control as its 0 line; a single well works as a reference. Controls can also come from a Control column in the sample names file. If one control's wells end up in more than one group, the Variants found card warns you.
  6. Compare wells directly. Click or drag across wells on the plate map to select them (a row letter or column number selects the whole row or column; Shift, ⌘ or Ctrl adds to the selection; Esc clears it). The plot next to the plate then shows the selected wells in colour, plus the control wells if Show controls with selection is ticked, and greys out the rest. Use the camera icon to save that view, e.g. one sample against its control.
  7. Hover over a curve or a well to see its sample, call, confidence and Tm.
  8. Remove bad wells: select them and click Exclude; select and click Include to put them back.
  9. Export. Use the camera icon above any plot (PNG or SVG; choose under Appearance), and the download buttons on the Results table tab. Save your settings so the same analysis can be repeated later.

What the settings do

Pre-/post-melt regions
Each curve is scaled so that the pre-melt region is 100% and the post-melt region is 0%. A straight line is fitted in each region, which removes the gradual background drift in fluorescence. This follows the pre-/post-melt approach of Thermo Fisher's HRM software and the methods of Palais & Wittwer (2009).
Smoothing
Reduces noise before taking the derivative. Heavy smoothing flattens sharp peaks and can shift Tm by a few tenths of a degree; 0.4 matches the instrument's own Tm values closely.
Temperature shift
Slides every normalised curve left or right so they all cross the chosen fluorescence level at the same temperature. This removes small well-to-well Tm offsets so differences in shape (typical of heterozygotes) stand out. On by default, because heating-zone offsets of a tenth of a degree between plate columns are common and otherwise blur the grouping (the example plate includes such offsets: try switching it off). Turn it off when variants differ mainly by Tm, because shifting removes that difference.
Group wells by
Curve shape uses the whole normalised curve between the two regions (recommended for genotyping). Tm only groups by melting temperature.
Confidence
How clearly a well belongs to its group rather than the next closest one (100% = unambiguous). Wells below the minimum are called Unknown.
Negative
Wells whose total fluorescence drop is much smaller than the plate median (e.g. NTCs, failed PCR). They are left out of the normalised plots and the grouping.
Clustering check tab
Shows the wells as points (closer points = more similar curves) and how cleanly the plate splits into 2, 3, 4… groups. Use it to sanity-check the number of variants.

Good practice

  • Include known controls for every genotype on each plate, and name the variants after them.
  • Compare samples only within one run and one assay: HRM is sensitive to salt, DNA concentration and plate position.
  • Treat calls as a guide; confirm unexpected or low-confidence wells by sequencing.
